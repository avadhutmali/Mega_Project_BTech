IdleGrid Agent — Portable Windows ZIP
====================================

1. Extract every file from this ZIP into one folder.
2. If automatic discovery does not work, open agent.properties in this same folder
   (next to run-agent.bat) in Notepad. Change master.url=auto to
   master.url=http://<master-PC-IP>:9090, for example
   master.url=http://192.168.1.25:9090. Save the file and restart run-agent.bat.
   The JSONBin ID is preconfigured. If the rendezvous bin is private, configure a
   read-only RENDEZVOUS_READ_KEY on this PC or in agent.properties.
3. Install Java 17 or newer if it is not already installed.
4. Double-click run-agent.bat and leave its window open while the agent is running.

Docker Desktop with its WSL2 backend must be installed and running before the agent
can execute compute jobs. Run setup.ps1 from an Administrator PowerShell to prepare
WSL2 and Docker on a lab PC. A reboot may be required after enabling WSL2.

The launcher, JAR, and agent.properties must stay together in the extracted folder.
Logs are written to the logs subfolder.
